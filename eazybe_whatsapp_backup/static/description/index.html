WhatsApp Chat Backup

Contact-linked WhatsApp chat backup for Odoo. This app adds a dedicated WhatsApp Chats by Eazybe view on Odoo contacts and renders synced messages as a conversation instead of raw notes.

Key Features

  • Contact-level WhatsApp conversation history
  • Incoming and outgoing chat bubble UI
  • Date separators and timestamps
  • Attachment links inside the conversation view
  • Conversation and message custom models for structured storage

How it works

After the app is installed in Odoo and the workspace is connected from Eazybe, the backend pushes WhatsApp chat backups into the Odoo conversation models. The contact form then shows the synced conversation inside the dedicated tab.

Requirements

This app is intended to work together with the Eazybe backend integration that sends chat backup data to Odoo.
